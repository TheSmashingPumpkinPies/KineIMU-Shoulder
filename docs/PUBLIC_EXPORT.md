# Audited public source copies

This is an independent curated public repository for KineIMU Shoulder. Its first
public commit starts new history. Original private development refs, preparation
commits, caches, unreviewed records and original/public mapping are not imported.

[PUBLIC_EXPORT.json](../PUBLIC_EXPORT.json) is a public-only integrity index. It
contains public paths, public byte sizes/digests and applicable licenses. The
untouched originals, their exact hashes and the private original/public mapping
remain with the maintainer and are not distributed in this repository.

The maintainer authorizes reviewed data copies under [ADR-015](adr/ADR-015-audited-public-data-copies.md).
Machine paths become relative paths or generic placeholders. Unique hardware/USB
identities and BLE addresses have consistent anonymous values. Model, firmware,
sampling/experiment conditions, numerical results, original sample/packet bytes,
failed records and actual acceptance dispositions are retained. Related public-copy
digest indexes and public checker anchors explicitly bind the reviewed copies.

Historical reports and source-head strings describe earlier local execution; their
public copies are not assertions of identical original metadata or of earlier
public Git availability. Original identity/digest mappings are private. Recomputed
public-copy numerical audits are reported separately from historical acceptance.

The original25-member synthetic sample CC0 annex and all sample-directory bytes
are unchanged. Additional701reviewed original data members have a separate dated grant in
[PUBLIC_DATA_LICENSE.md](PUBLIC_DATA_LICENSE.md). Root MIT covers original project
code/documentation. Existing Apache-2.0 firmware and full third-party notices retain
their terms. Embedded archived source retains its per-member software licenses.

See [audit report](PUBLIC_AUDIT.md), [availability](PUBLIC_EVIDENCE.md),
[verification](PUBLIC_VERIFICATION.md) and [benchmark reproduction](PUBLIC_BENCHMARK.md).
