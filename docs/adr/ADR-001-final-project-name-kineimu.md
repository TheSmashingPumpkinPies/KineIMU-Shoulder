# ADR-001: Final Project Name — KineIMU

> Superseded by ADR-005 for naming; original decision below is historical.

- Status: Accepted
- Date: 2026-09-05

## Context

The earlier working title `OpenMotion` had multiple public-name collisions and was not suitable as the final repository/package identity.

## Decision

The final project name is **KineIMU**.

```text
Display name: KineIMU
Repository: kineimu
Python package: kineimu
Import namespace: kineimu
CLI: kineimu
Firmware: KineIMU Firmware
```

## Consequences

- `OpenMotion` is retired.
- All active documentation and code use `KineIMU` / `kineimu`.
- Future renaming requires a new ADR.
