# ADR-014 — Independent curated public repository

Status: Accepted

Date: 2026-09-29

The maintainer created https://github.com/TheSmashingPumpkinPies/KineIMU-Shoulder
and requested formal public repository curation. Keep independent public Git history
and exact source provenance; private source refs/handoffs and legacy reference pack
are not imported. This actual GitHub casing leaves project title, reserved CLI and
import namespace unchanged. Original acceptance and public-candidate checks are
distinct; no tag/Release/PyPI is implied.

Preserve scientific source and frozen inputs/evidence. Public navigation/metadata
changes are recorded. Retain MIT for original Python code/documents, existing Apache
firmware SPDX and full third-party texts. Sample CC0 covers the explicit25files;
additional original data requires its own recorded grant. Build a complete test/Demo/
benchmark dependency closure, verify a fresh clone and retain failed attempts.
