## Implementation and evidence boundary

`kineimu_shoulder/thorax.py` adds a separate explicit processed operation
`prepare_thorax_common_grid`. It consumes post-alignment
`SegmentOrientationStream`, `ClockMap`, alignment/calibration, configuration
and optional heading/drift records. It preserves all original device
times/quaternions, mapped times, original-index brackets (equal indices for
exact samples), SLERP weights, source QC, common grid, validity/reasons,
method/version, uncertainty and configuration/hash. Failed interpolation
keeps its bracket/weight; extrapolation has none. Clock-validity filtering
does not renumber original indices. No adapter resampling or second alignment.

`compute_thorax_excursion` retains the exact CP2 metrics and optional trace
in `ExerciseThoraxResult`; each `RepetitionThoraxResult` retains its CP2
repetition and original offending rows/intervals. Consumption reconstructs
CP2 and trace preparation to reject forged/mutated derived records. Source
node/clock/epoch/hash/world, map, alignment, calibration, grid, timing limit
and complete configuration must bind to the M2/M3/CP1 records.

For each eligible closed repetition, SciPy computes quaternion
`q0^-1 * qt` and rotation matrices. The frozen Z-Y-X matrix equations
extract extension=-beta, lateral=-alpha, axial=gamma in movement-start T0
axes. Signed extrema include zero; magnitude is max absolute excursion.
Principal branches have no unwrap. Every singular row or component jump
greater than pi makes all three components unavailable. Reasons coexist;
the first is primary. Invalid scalar values are NaN, not numeric zero.

Written extraction justification: a failing near-singularity test proved
SciPy `as_euler` issues gimbal-lock output at a fixed threshold larger than
the configured cosine floor. The contract already specifies equivalent
matrix extraction; using `atan2(-D31, hypot(D11,D21))` for beta and its
specified alpha/gamma formulas preserves that floor and stable principal
angles. This adds no new rotation algorithm or dependency.

Independent heading and conservative duration-specific drift records carry
world, method/reference hash, covered window and supported/assumed status.
Neither startup heading nor gravity supplies a zero drift bound. Missing,
uncovered, exceeded or incompatible evidence excludes only the proxy.
Explicit assumptions give numerical `Assumed/Experimental` and false
anatomical eligibility. Physical eligibility additionally requires measured
thorax axes and supported upstream evidence; synthetic axes remain ineligible.
Excluded relative candidates receive unavailable proxies with original reasons.

The shared exact-association helper now treats two scalar NaNs as equal,
matching its existing array NaN policy. The initial CP3 run exposed that
normal unavailable CP2 scalars otherwise falsely fail reconstruction.
Changed vs unchanged metric values remain distinguishable.
