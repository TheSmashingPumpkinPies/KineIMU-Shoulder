## Implemented interface

`kineimu_shoulder.summary.summarize_exercise` accepts authentic CP2 metrics
or CP3 proxy results and a required `SummaryContext`. One call summarizes
one declared set/session analysis window. Original M2/M3/CP1/CP2/CP3
records remain nested, including source hashes, QC breaks, elapsed valid/
invalid support, metric validity, assumptions and physical eligibility.
Inputs are reconstructed before aggregation; altered stage metrics or
summaries are rejected, including mutation inside nested arrays/dicts.

Context supplies UTC start (optional for a standalone summary, required
for comparison), both calibration IDs, both alignment artifact hashes,
pipeline backend name/version/configuration hash, explicit grid policy
method/version/configuration identity, and synthetic generator/version.
These are caller declarations, not evidence newly measured by CP4. They
must describe the complete processing chain, not just one selected backend.
Raw recording hashes are not alignment artifact hashes.

- Detected, valid and excluded counts; separate partial-start, partial-end
  and interrupted counts. Invalid global analysis has unavailable counts.
  Exclusion reasons retain candidate IDs and explicit counts; overlapping
  reason counts are not a partition of excluded candidates.
- Every relative scalar has arithmetic mean, maximum and its own n, including
  rest and speed of empty/nonempty phases. Excluded envelopes contribute
  nothing. Valid quiet windows have zero counts and unavailable statistics.
- ROM range for n>=1, sample SD with NumPy ddof=1 for n>=2, CV only above
  the explicit mean floor. No SEM or clinical consistency score.
- Active time sums eligible rep durations; active cadence is valid_count/
  active_time in s^-1, excluding rest. Empty active time is unavailable.
  Window elapsed duration is an independent Observed quantity; nested QC
  valid/invalid support is preserved, never treated as observed motion.
- Proxy means/maxima/n for each signed minimum, signed maximum and magnitude;
  proxy valid/unavailable counts concern otherwise eligible relative reps.
  Missing proxy never excludes relative metrics. Aggregation groups values
  by evidence label and anatomical eligibility; assumed proxy values stay
  distinct from supported relative values.

`compare_summaries` validates every summary and returns every chronological
pair, suitable for separately declared sets or longitudinal sessions. Each
analysis has a unique session/result ID; explicit UTC ties sort by that ID.
Duplicate IDs, missing UTC or malformed/non-UTC timestamps are input errors.
No pooled summary is created.

Exact comparability keys: definition versions, complete configuration,
side/exercise, protocol ID/version, frozen frame conventions, calibration
IDs/hashes, alignment hashes and transforms/neutral/mount/evidence fields,
clock methods/status, heading method/world/transform/status, evidence
stratum, interpolation/gap/timing uncertainty policy, proxy preparation/
heading/drift policy, backend/version/configuration, grid policy and source
type/generator/version. Alignment raw-reference hashes and clock epoch/fit/
offset/coverage are per-record lineage, not equal-session requirements.
The full original records are retained. Recalibration/remount differences
remain incomparable. Missing proxy vs evidenced proxy is conservatively
incomparable because proxy processing policy is not equal.

Incomparable pairs expose sorted exact differing keys and `differences=None`.
Comparable scalar means yield later minus earlier in SI with both n,
evidence and anatomical eligibility. Unavailable values retain
`comparison_metric_unavailable` and NaN, never a difference from zero.
