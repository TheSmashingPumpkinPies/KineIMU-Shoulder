## Result and API

**CP2 passed at direct-input synthetic numerical/evidence scope.**
`kineimu_shoulder.exercise.compute_repetition_metrics(segmentation)` accepts
the CP1 `SegmentationResult` and returns an `ExerciseMetricsResult` retaining
that exact input and all detected candidates. Each repetition contains its
unchanged candidate, retained maximal `hold_runs_us`, original grid interval
indices for elevation/return/hold, and named `RepetitionMetrics` scalars.
Every scalar has value, validity, reason, SI unit, evidence label and
anatomical eligibility. In-memory unavailable values are NaN; canonical JSON
conversion remains CP5. No session summary or thorax proxy is implemented here.

```python
from kineimu_shoulder.exercise import compute_repetition_metrics

result = compute_repetition_metrics(segmentation)  # existing CP1 result
for repetition in result.repetitions:
    rom = repetition.metrics.rom_rad
    if rom.valid:
        print(repetition.candidate.id, rom.value, rom.unit)
```

The stage revalidates CP1 against its nested M2/M3 inputs and complete hashed
configuration, rejecting forged boundaries/eligibility and mutable-array
corruption. M3 supplies closed-interval ROM and elapsed duration. Peak is
maximum elevation, independently of ROM. Rep and phase speed statistics use
M3 principal three-dimensional interval magnitude: maximum and
sum(speed*observed_dt)/sum(observed_dt), never a sample mean or signed
elevation derivative. Identical sampled endpoints cannot detect unobserved
within-interval revolutions; this existing M3 aliasing limit remains.

Hold requires both endpoints in the peak band, speed within the threshold,
and a maximal contiguous run meeting the elapsed minimum. Equality passes
with no threshold slack. Qualifying intervals transfer from chronological
rise/return to hold; each observed candidate interval has one owner.
Chronological phase gates remain CP1 supports before hold removal. An empty
owned phase has valid zero duration and unavailable speed (`empty_phase`).
No detected hold is valid zero hold duration. Separate short runs do not
combine; below-band pauses do not qualify.

Excluded candidates retain all CP1 QC/censoring/reasons and diagnostics;
every scalar is unavailable with the primary candidate reason. They expose
no eligible interval ownership or hold runs. Subsequent stages must check
metric validity before aggregation. Preceding rest is available only between
adjacent eligible detected candidates with complete intervening row/speed/gap
continuity. Otherwise it is unavailable (`rest_interrupted`), including the
first repetition. No leading/trailing rest is fabricated.
