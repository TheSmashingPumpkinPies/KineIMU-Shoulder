# M3 CP0 Contract and Expected-Value Review

Date: 2026-09-25 (Asia/Shanghai). Scope: contract and analytical fixtures
only; no M3 production calculation or synthetic integration is claimed.

| CP0 review item | Disposition and trace |
|---|---|
| M2.4 input matches the existing interface | `RelativeOrientationResult` already carries `common_time_us`, `quaternion_th`, validity/reasons, source hashes, two maps, heading relation and processing limits. M3 requires two *additional* explicit alignment records because M2.4 does not carry them. No single-node `q_WN` substitution is allowed. |
| Frames and metric scope | `protocols/M2_PROCESSING_CONTRACT.md` and `DATA_FORMAT.md` use active scalar-first rotations, thorax +X anterior/+Y left/+Z superior, and humerus +Z proximal. The M3 formula rotates that long axis, yielding unsigned humerothoracic elevation. `01_PROJECT_SPEC.md` distinguishes ROM, peak, and 3-D angular speed. |
| Unit and interval policy | Internal rad, rad/s, s; source/grid timestamps int64 µs. Exact closed sample endpoints, inclusive rows, positive time, 500000 µs **fixture** gap limit, no endpoint interpolation. Session calculations require their own recorded positive gap value. |
| Evidence and validity | M2 row reasons survive; missing/expired alignment or absent clock/heading blocks numeric output. Assumed evidence stays `Assumed/Experimental`. Synthetic expected values never become physical or clinical validation. M1 pair lacks the necessary anatomical evidence. |
| Independent truth | `tests/fixtures/M3_KNOWN_MOTION.md` derives E cases by rotated +Z vectors and dot products, S cases by principal rotation divided by observed seconds, and R cases by stated extrema and exact endpoint differences. It was written before any M3 implementation. |
| Tolerances and exclusions | Exact synthetic angle/ROM `1e-10 rad`, speed `1e-10 rad/s`, duration `1e-12 s`; invalid cases require exact reason and absent numeric result. Aliasing of a full revolution between two samples is explicit. |
| Public boundary | No M1 packet, seven-column normalized table, raw source, dependency pin, firmware or public schema change. The proposed `m3-kinematics/1.0` is a separate derived artifact. |

CP0 exit: contract and expected values are frozen for test-first CP1 work.
This review establishes specification consistency and analytical expectations;
CP1–CP4 numerical checks and the overall M3 acceptance criterion remain open.
