## Implementation and scope

`kineimu_shoulder.exercise.segment_shoulder_repetitions` consumes explicit
M3 `ElevationResult` and `AngularSpeedResult`, exercise/side, exact window,
session/protocol identity, complete `ExerciseConfig`, A/B calibration hashes
and processing hash. Nested original M2/M3 records preserve clock/heading,
alignment, source identity, interpolation policy, evidence and QC.
Configuration is canonicalized and SHA-256 hashed; SI values and the required
caller gap are retained. No raw/acquisition schema, dependency, firmware or
M2/M3 interface changed. Hardware remains frozen.

This is a CP1 in-memory stage result, not the complete CP5 JSON export.
It exposes observed candidate boundaries, confirmations, earliest peaks,
rise/return supports, censoring/interruption, exclusion reasons, plane
durations/fractions and failing/non-identifiable interval indices.
Analysis counts distinguish quiet valid input from missing global evidence
or no usable continuity. All QC breaks retain original row/interval indices
and reasons; observed valid plus invalid elapsed duration equals window time.
Failed start debounce is a separate diagnostic. All detected envelopes remain
available, including excluded candidates; their observed durations are
diagnostics, not eligible per-repetition metric values.

Plane verification rotates humeral proximal +Z with existing SciPy-backed
frame operations, uses anterior `-u_x` and side-aware lateral `-s*u_y`, and
tests both interval endpoints. Fraction uses observed eligible microseconds,
not row count. Unobservable direction does not pass. Exercise labels remain
caller supplied. The project-specific state machine follows the written CP0
justification; amplitude gating reuses M3 closed-interval ROM.

Each continuity block starts unarmed. Confirmations use observed elapsed
time; candidates start/end retrospectively at the first confirming-run row.
No hidden smoothing, endpoint interpolation, repaired NaN, gap bridge or
local-maximum splitting. Return-tail interruption excludes the candidate.
Synthetic results are Derived, assumed inputs retain Assumed/Experimental;
no stronger anatomical evidence is inferred.

CP2 hold/phase/per-repetition metrics, CP3 thorax input/proxy, CP4 summaries
and comparisons, and CP5 deterministic artifact integration remain open.
No physical anatomical or clinical validation is claimed. The M1 pair still
lacks independent pairwise clocks, common heading and measured alignment.
